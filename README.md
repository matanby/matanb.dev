# matanb.dev

Personal site for Matan Ben Yosef. Static HTML, CSS and JavaScript, no build step, no
dependencies.

## Local preview

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Layout

| Path | Contents |
|---|---|
| `index.html` | The whole page, including the JSON-LD block |
| `css/` | Styles, and the self-hosted font faces |
| `js/main.js` | Theme toggle, scroll reveal, and video playback control |
| `assets/` | Fonts, publication media, and the social card |
